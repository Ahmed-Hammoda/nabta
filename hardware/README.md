## Folders

| Folder | Content |
|---|---|
| [`components/`](components/) | Final component list, prices and where to buy in Tunis |

| [`firmware/`](firmware/) | Code that runs on the microcontroller / edge device |

## Key requirement

The main board must be able to run a **small language model locally** (e.g. Raspberry Pi 5, 8 GB).

## Measurements

- Soil moisture
- Air temperature and humidity
- Light level
- Water tank level (optional)
