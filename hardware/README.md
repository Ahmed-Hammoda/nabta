| Folder | Content |
|---|---|

## Key requirement

The main board must be able to run a **small language model locally** – a Raspberry Pi. Sensors and the pump connect directly to it.

## Measurements

- Soil moisture
- Air temperature and humidity
- Light level
- Water tank level (optional)
