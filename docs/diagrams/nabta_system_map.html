Overview

The code decides. The AI explains.

Every 30 minutes the Pi reads the sensors, saves one row, and the rules decide whether to water and which alerts to raise. Only then does the local AI model write a short explanation for the app. Code checks every AI answer and replaces a wrong one with a fixed sentence.
